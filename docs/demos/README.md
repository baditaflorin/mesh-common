# Mesh demo catalog feed

`catalog.json` is the public, machine-readable directory of every recorded
Mesh demo. It is generated by `scripts/build-demo-dashboard.mjs` from the demo
recordings, the services registry, and the centralized taxonomy; consumers
should use this file instead of scraping `index.html` or maintaining their own
app list.

Published URL:

`https://baditaflorin.github.io/mesh-common/demos/catalog.json`

## Contract

The top-level object has `schemaVersion`, `generatedAt`, `total`, and `demos`.
Each demo exposes stable `id`, `name`, `description`, `liveUrl`, `sourceUrl`,
`status`, `recordingStatus`, `recordingUrl`, `previewUrl`, `trl`, `category`,
`subcategory`, and `useCases` fields. URLs are absolute so the feed can be
used from any static site.

`status: "ok"` means that the recording gate found an `OK` record plus a
non-empty GIF. Consumers should treat unknown fields as forward-compatible and
use `schemaVersion` for breaking changes.
